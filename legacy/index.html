ideas de regalos especiales

¿Qué regalar cuando quieres decir algo?

Un regalo original no tiene que ser raro ni caro: tiene que tener sentido para quien lo recibe. Una caja de vinilos usados convierte una historia compartida en canciones, una nota y pequeños detalles que se quedan.

  • Para quien tiene de todo: un disco elegido por lo que hace recordar.
  • Para una pareja: canciones de un viaje, una primera cita o una época.
  • Para pedir perdón o dar las gracias: un mensaje que se escucha sin prisas.
